# 栖 · 生活工作台

一个安静的多功能生活工作台，把每天的记录整理成井井有条的生活。

## 功能一览

### 📒 账本
- 快速记一笔：支出 / 收入、分类、备注、日期与时间（精确到秒）
- 月度概览：结余、消费结构图、月度对比、预算管理、日均预算自动计算
- 明细按日分组：每天收支一目了然，支持按备注 / 分类 / 金额搜索
- 每笔记录均可查看详情、编辑与删除

### ✅ 习惯
- 新建勾选 / 计数 / 数值型习惯，设定每日目标
- 30 天热力图 + 连续打卡天数统计
- 一键打卡，进度实时更新

### ⚖️ 身体
- 体重与体脂率记录，7 日均线、目标进度追踪
- 体重变化曲线、每日热量缺口估算
- 历史记录可查看详情、编辑与删除

### 📅 日程
- 月历视图，日期快速切换，标记有事项的日子
- 添加事项：日期、时间（精确到秒）、分类、备注
- 到达设定时间时应用内提醒

### 🛒 待买
- 待买清单与已购记录，自动累计预计花费
- 勾选已购时自动记录购买时间

### 🗂 数据
- 一键导出备份，随时从备份恢复
- 数据概览：各模块记录数一目了然，可逐条查看
